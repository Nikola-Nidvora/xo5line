XO5 — админ-панель

Вход под тем же именем и паролем, что и в игре.

Адрес входа собирается как «имя@xo5line.local». Для нового проекта xo5line: сначала зарегистрируй имя в игре v1.28.2, затем создай в консоли Firebase документ-маркер admins/{твой UID} (коллекция admins, ID документа равен UID из коллекции users). Без маркера вход сюда запрещён правилами.

Доступ запрещён

Аккаунт с UID — не является админом: в коллекции admins нет документа-маркера с таким ID.

Рейтинг игроков

Процент побед = победы / (победы + поражения + без результата) × 100. Средняя длительность считается только по завершённым играм с победителем, из времени партии вычитается суммарное время пауз.

Алгоритм 1 — Протухшие игры

Признак: в игре не было ни одного хода ≥ N дней (статус не важен). Якорь последнего хода: turnStartTime → gameStartTime → createdAt. Действие: полное удаление документа игры, документа activity и карточки каталога — без результата и без начисления статистики. Игры с ходами живут неограниченно долго.

Алгоритм 2 — Протухшие аккаунты

Признак: вход в аккаунт старше ≥ N дней (lastLoginAt → createdAt). Действие: purge активных игр игрока (waiting/playing/paused) без результата → создание карточки в /trash с именем/email/снимком статистики → удаление документа users/{uid}. Запись входа в Auth удаляется вручную в консоли Firebase; админка лишь отмечает карточку «Auth удалён» в блоке «Корзина».

Корзина (/trash)

Очередь ручной зачистки: карточки аккаунтов, ждущих ручного удаления записи Auth в консоли Firebase. После зачистки Auth в консоли нажми «Auth удалён» — карточка отметится выполненной. Кнопка «Убрать из корзины» предупреждает, если Auth ещё не зачищен (иначе запись входа теоретически пересоздаст профиль).

Сиротские документы activity

Документы activity/{id}, для которых нет соответствующей игры в games. Накапливаются из-за старых версий игры и сбоев удаления. Кнопка находит их, показывает список и удаляет после подтверждения. Запись в журнал: activity_orphans_purged.

Эти значения сохраняются в config/app, но игровой файл их ПОКА не читает. Изменение сейчас не влияет на игру и будет применено игрой после версии v1.28.x.
